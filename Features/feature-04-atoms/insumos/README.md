# Insumos — Feature 04 Atoms

Colocar aquí los insumos de diseño que alimenten las tasks de átomos:

- Enlaces Figma por componente (URL + `node-id`).
- Capturas de referencia si el MCP no está disponible en CI.
- CSV o listados de variantes (estados, tamaños) acordados con UX.

**Regla:** los valores cromáticos y de espaciado deben poder mapearse a tokens Feature 02 (`--ds-*`) o a datos en `Ligth_mode.tokens-3.json` / `darkmode.tokens-3.json`. Si un valor no existe, **primero** propuesta en Feature 02 / capa de tokens, **después** implementación en componente.
