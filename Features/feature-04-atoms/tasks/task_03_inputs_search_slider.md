# Task 03 — Inputs, Search y Slider

**Feature:** 04 Atoms  
**Agente:** `@Agents/fullstack-design-system`

## Objetivo

Consolidar **Inputs** (campos de texto y variantes), **Search** (campo con icono / clear) y **Slider** (control de rango) como átomos tokenizados.

## Entregables

1. Vista Inputs existente ampliada o refactorizada a patrones `--ds-*`.
2. Vista **Search** (ruta acordada en task 01: propia o bajo Inputs).
3. Vista **Slider** nueva o integrada según plan de rutas.
4. Panel de controles en línea con otros átomos (tamaño, estado, disabled).

## Reglas

- Placeholders y bordes: tokens; focus ring: `var(--ring)` o token DS equivalente.
- Slider: track/thumb sin hex sueltos; usar theme o tokens semánticos.
